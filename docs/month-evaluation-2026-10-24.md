# Прогноз +15 минут в течение месяца: TR169

Проверка проведена 24 октября 2026 по уже скачанному архиву GIRO.
Обучение: целевые интервалы с 01.09.2024 до 01.09.2025 UTC.
Оценка: весь сентябрь 2025, 2880 возможных интервалов.
Модель обучена один раз; в сентябре параметры не обновляются.
Наблюдения поступают в признаки последовательно по мере завершения интервалов.
Перед обучающим годом используется неделя истории для лагов.

Это отдельная экспериментальная модель `HistGradientBoostingRegressor`.
Рабочий артефакт API не оценивался и не заменялся. Достаточный локальный архив
есть только для TR169; выводы пока относятся к одной станции и одному месяцу.
Сентябрь уже использовался для предыдущего эксперимента без CS, поэтому этот
повторный расчёт не является новым независимым финальным тестом.

## Подготовка и результаты

Используются только физические foF2 0,5–25 МГц с известным конечным CS >= 50.
Неизвестный CS, -1 и низкие значения исключаются также из целевых наблюдений.
Пропуски не заполняются. Во входах — завершившийся интервал foF2, прошлые лаги,
разности, скользящие средние и календарные признаки. Внешние индексы не используются.
Прогнозируется среднее следующего 15-минутного интервала, а не мгновенное значение.

| Показатель | Значение |
|---|---:|
| Обучающие пары | 20 812 |
| Выданные прогнозы | 1944 / 2880 (67,5%) |
| Пары с доступным следующим фактом | 1712 / 2880 (59,4%) |
| Пропуск прогноза из-за отсутствия допустимого текущего foF2 | 936 |
| Прогноз выдан, но следующий факт отсутствует | 232 |

Оба метода оценены на одинаковых 1712 парах:

| Метод | MAE, МГц | RMSE, МГц |
|---|---:|---:|
| Модель | 0,195408 | 0,328514 |
| Следующее среднее равно текущему (persistence) | 0,204006 | 0,343584 |

Снижение MAE — 4,21% (0,00860 МГц). Выигрыш небольшой; устойчивость на других
станциях, месяцах и при реальных задержках публикации пока не установлена.
Старые метрики режима CS off рассчитаны на других парах; напрямую сравнивать
их с текущими как улучшение модели нельзя.

## Проверка утечки

- Обучающие целевые интервалы завершаются не позже границы сентября.
- Удаление всех сентябрьских сырых строк оставляет обучающие признаки и цели неизменными.
- Физически обрезанные архивы на 02.09 12:00, 16.09 00:00 и 29.09 12:00 UTC
  воспроизводят прошлые входы и прогнозы точно: 120, 902 и 1885 прогнозов,
  максимальное расхождение 0.
- Текущие измерения во всех строках предшествуют моменту выдачи.
- Конфликтующих повторных foF2 на одном времени нет.
- 20 тестов ML-сервиса прошли, включая временные границы и строгую обработку CS.

В этих проверках прямой утечки будущих строк не обнаружено. Однако архив
содержит время измерения, а не время появления у пользователя. Доступность
принята на конец интервала; поздние исправления архива исключить нельзя.
Это архивная оценка, а не точное воспроизведение исторического онлайн-сервиса.
