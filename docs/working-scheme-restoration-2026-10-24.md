# Восстановление истории и проверка рабочей схемы +15 минут

## Полученный результат

Восстановлены все 32 новых файла GIRO; запрос GM037 за 2024 год после HTTP 429
успешно повторён. Файлы TR169 использованы повторно. Для 16 станций подготовлены
все 152 столбца без полностью отсутствующих входов; фактическая заполненность
на строках с допустимым текущим foF2 составляет 90,2–98,3%.
У RO041 GIRO вернул корректные пустые архивы за оба запрошенных периода;
для этой станции оценка качества невозможна, нулевой ошибкой она не считается.

Кандидат обучен на 427 382 парах предыдущего года. Сентябрь в обучение не входит.
На 16 станциях выдано 40 425 прогнозов из 46 080 интервалов (87,7%);
для 38 750 прогнозов есть следующий допустимый факт (84,1% интервалов).
Если включить в знаменатель также RO041 без архива, покрытие выдачи по всему
зафиксированному набору из 17 станций составляет 82,6%.

## Зафиксированный эксперимент

Для восстановления 24 октября 2026 зафиксированы 17 станций по текущим
активным кандидатам GIRO: AL945, AT138, CAJ2M, DB049, EB040, GA762, GM037,
GR13L, IF843, JI91J, JR055, NI135, PQ052, RO041, SO148, TR169, WA619.
Состав сохранён до расчёта ошибок и не отбирался по качеству на тесте.
Остальные коды исходного каталога и дополнений GIRO не объявляются проверенными
по качеству: предыдущий аудит записывает их причины недоступности отдельно.

История: с 24.08.2024 до 01.10.2025 UTC. TR169 использует ранее скачанные
месячные файлы с 25.08.2024. Предыстория нужна для лагов до семи суток.
Обучающие целевые интервалы: 01.09.2024–31.08.2025.
Тестовые целевые интервалы: сентябрь 2025, 2880 возможных выдач на станцию.
Сентябрь ранее уже исследовался на TR169; это повторяемая архивная оценка,
а не новый независимый финальный тест.

Сравниваются на одинаковых парах:

1. Исходный рабочий артефакт API, без изменения весов.
2. Кандидат, обученный заново на годе по рабочей схеме из 152 входов.
3. Persistence: следующее среднее равно последнему завершившемуся среднему.

Кандидат использует `HistGradientBoostingRegressor`, 300 итераций,
learning_rate 0,05, l2 0,01, random_state 42; случайная ранняя остановка отключена.
Параметры и список входов не подбираются по сентябрьским ошибкам.
Рабочая модель и кеш API не заменяются.

## Восстановление источников

GFZ: по 3224 записи Kp/ap и по 403 записи Ap/Fobs/Fadj, всего 7657.
OMNI: 9672 часовых записи за запрошенное окно.
Исходные ответы и SHA-256 сохранены. Исправлены имена сырых GFZ-файлов:
разные индексы `ap` и `Ap` больше не перезаписывают друг друга на Windows.

GIRO сохраняется порциями по годовым границам. Возобновляемый загрузчик
проверяет станцию и окно в заголовке, отклоняет HTML/ERROR и пишет файл атомарно.
Разбор всех станций в память одновременно исключён: скачивание сырых файлов
и подготовка одной станции выполняются отдельно. Загрузчик использует общий
с рабочими Linux-контейнерами ограничитель запросов и cooldown.
Неудачные запросы не интерпретируются как отсутствие ионосферных наблюдений.

Полный обход каталога временно останавливается на время исторического сбора,
чтобы сократить конкуренцию за GIRO; API и обновление выбранных станций остаются
работать. После восстановления обход возвращается в работу.

## Признаки и время доступности

Используются функции рабочей нормализации и `build_station_features`.
Список и порядок 152 входов берётся из исходного production-артефакта.
Текущий foF2 и цели строятся только из измерений 0,5–25 МГц с конечным CS >= 50;
неизвестный CS исключён. hmF2 и TEC ограничены широкими физическими пределами.
Пропуски foF2 не интерполируются; внешние пропуски не заменяются фиктивными значениями.

Исторический профиль доступности отличается от прежнего использования индексов
с начала их периода:

| Источник | Минимальная задержка от метки периода | Срок переноса после доступности |
|---|---|---|
| OMNI Bz, Dst, скорость, плотность | 1 час | 1 час |
| GFZ Kp/ap | 3 часа | 3 часа |
| GFZ Ap/Fobs/Fadj | 1 сутки | 1 сутки |

NASA указывает, что метка 00:00 для первого часового среднего соответствует
наблюдениям за 00:00–01:00. [OMNIWeb Help, Question 4](https://omniweb.gsfc.nasa.gov/html/ow_help.html).
Kp/ap описывают трёхчасовые интервалы, а Ap является средним за день.
[GFZ: About Kp](https://kp.gfz.de/en/about-kp).

Это консервативные нижние границы доступности после окончания периода,
а не измеренные времена публикации. Definitive-индексы и исправленные архивы
могли реально появляться позднее. Поэтому результат не является точным
воспроизведением онлайн-сервиса в прошлом. Новому кандидату при внедрении
понадобится согласованный профиль подготовки входов.

Прогноз — среднее следующего 15-минутного интервала, выдаваемое после окончания
предыдущего. Наблюдения сентября последовательно входят в признаки завершившихся
интервалов; параметры модели весь месяц фиксированы.

## Контроль воспроизводимости

- Для каждой станции физическое удаление сентябрьских сырых строк обязано
  сохранять обучающие входы и цели без изменений.
- Обучающая цель должна полностью завершиться не позже границы сентября.
- Список входов не содержит целевых столбцов, выходов других оценочных прогонов
  или сглаживаний с доступом к будущему.
- Неизвестный CS и пропуски не скрываются при расчёте покрытия.
- Сохранены хеши исходников, конфигурации, сырых и подготовленных данных.
- Возобновление подготовки разрешено только при совпадении входных,
  программных и выходных хешей.
- Обучение сохраняет периоды, состав станций, число пар, покрытие и метрики
  каждой станции; ограничение строк не используется.

Основные локальные результаты: `../output/working_scheme_20261024/`.
