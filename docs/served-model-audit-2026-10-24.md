Для всех 16 станций с таблицами признаков входы получены из работающего Data API,
локальный расчёт этого артефакта сравнен с ML API. Все 16 результатов совпали
с учётом округления API до 0,001 МГц. Неактивные станции не включались в выдачу
и не объявлялись проверенными по качеству.

В обычной текущей таблице полностью отсутствуют 95 из 152 входов; у отдельных
станций — 97 или 106. Это внешние индексы и лаги, в том числе 12 часов,
сутки, двое суток и неделя при имеющемся окне истории около 11 часов.
Деревья модели действительно используют часть отсутствующих входов.
Модель обрабатывает NaN, однако техническая возможность получить число
не доказывает качество при таком составе входов.

## Проверка ошибок по имеющимся текущим таблицам

На 16 станциях набралось 628 пар с допустимыми текущим и следующим foF2,
CS >= 50 и точным шагом 15 минут. По общим парам модель имеет MAE 0,313649 МГц,
persistence — 0,321583 МГц: снижение ошибки 2,47%. По отдельности модель лучше
на 10 станциях и хуже на 6; для GA762 только четыре пары.

Это ретроспективный расчёт по коротким текущим таблицам, которые могут включать
поздние исправления. Он не является месячным тестом или подтверждением
доступности всех этих входов в прошлом.

## Сентябрь 2025: диагностический расчёт рабочего артефакта

Полный архив месяца с предысторией локально есть только для TR169. Подготовлены
входы с именами и лагами рабочего feature pipeline, строгим CS >= 50 и точной
сеткой. Рабочий артефакт загружен как есть, без обучения. Исторических внешних
индексов нет: 90 входов полностью отсутствуют, из них 66 используются деревьями.

На 1712 общих парах MAE модели 0,367450 МГц, persistence — 0,204006 МГц;
RMSE соответственно 0,505400 и 0,343584 МГц. Это GIRO-only диагностика с
неполным вектором входов, а не полноценная оценка рабочего конвейера.
По ней нельзя приписывать модели предыдущий выигрыш 4,21% или делать
окончательный вывод о качестве при полном наборе признаков.

## Вывод и необходимые данные

API технически использует проверенный рабочий файл, однако задача оценки
качества всех станций за месяц пока не закрыта. Для её завершения нужны:

1. Исторические GIRO и внешние индексы за выбранный месяц с предысторией
   для всех проверяемых станций; для обучения по плану — ещё предыдущий год.
2. Воспроизводимое обучение рабочей схемы с исправленным временным разделением,
   сохранением списка станций, отпечатков данных и временных границ.
3. Оценка фиксированного артефакта на заранее выбранном месяце без подбора
   параметров по тесту. Отдельно — доступность признаков при задержках источников.

Рабочие модель, кеш и настройки сервиса в этом аудите не заменялись.
23 теста ML-сервиса прошли. Добавлены проверки, что оценка не переносит цель
через пропуск временной сетки и отвергает неизвестный CS следующего факта.
